# 前端去 AI 味快速檢核與評分清單 (Checklist)

本清單用於在產出前後快速掃描介面，以客觀量化指標評估頁面的「AI 味」殘留程度，並提供立即可用的替換方案。

---

### 評分級距與處置原則

- **0–1 分：乾淨無痕跡且具備實體工藝 (Clean & Crafted)**
  - 介面具備鮮明品牌個性、物料觸感、空間張力與充裕留白。准予交付。
- **2–3 分：中度 AI 味或公版收斂 (Mild Slop / Monoculture)**
  - 存在部分套路（如局部漸層、等寬卡片，或退回單一枯燥論文風配色）。必須執行**定向去 AI 味與注入工藝重構**。
- **4 分以上：重度 AI 味 (Heavy AI Slop)**
  - 頁面充斥標準公版特徵，品牌辨識度極低。必須立即**暫停產出，依據 `DESIGN.md`、設計諮詢矩陣與負向黑名單進行結構性重構**。

## 2. 人類設計師審查 12 問 (Twelve Critique Questions)

在審查任何介面草稿或程式碼時，主動提出以下 12 個批判性質疑：

1. **Logo 遮蔽測試**：如果把 Logo 遮住，訪客能分辨這是你公司的產品，還是又一個模版化週末 Side Project 或枯燥論文範本？
2. **物料觸感**：頁面是否具備物理真實感（微噪點 SVG 紋理、頂部 1px 內切光學高光、消光塑料或實黑位移陰影），還是死板平滑的數位向量？
3. **字級與混搭張力**：主標題字級跳躍比是否 ≥ 3.0 倍？是否具備字體同句混搭（如在無襯線大標內嵌入優雅 *Italic Serif*）或背景裝飾浮水印？
4. **留白節奏**：桌面端區塊垂直內距是否達到 `160px`？使用者滾動時是否有足夠的視覺呼吸空間？
5. **色彩克制與獨特性**：全頁是否守住「最多 3 個強調色、各色出現不超過 3 次」？是否避開了紫粉漸層與千篇一律的陶土紅複讀？
6. **空間破格與縱深**：是否有邊緣外溢 (Bleed-out) 的展示元素、跨區塊層疊重疊 (Overlapping)、或左側黏性側欄導覽 (Pinned Rail)？
7. **按鈕物理回饋**：按鈕是否有真實的物理按壓阻尼 (`active:translate-y-0.5` 或 `active:shadow-none`)，還是標準無感的純色切換？
8. **對齊張力**：內文與說明段落是否一律靠左對齊？是否徹底杜絕了全頁 `text-center`？
9. **版面多樣性**：是否連續兩個區塊都使用了圖示卡片？能否將其中一區重構為開放式表格、數據遙測矩陣或非對稱雙欄？
10. **文案真實度**：標題與副標題是否講述具體的功能細節與工程數字，而非「Unlock the future」等空話？
11. **工程符號細節**：是否有座標戳記、結構標尺符號或即時呼吸脈衝燈等工藝細節點綴？
12. **無障礙與鍵盤互動**：按 Tab 鍵巡覽時，每個按鈕與輸入框是否有醒目的焦點環？表單出錯時是否有清楚的紅字錯誤提示？

## 3. 快速修復速查表 (Quick-Fix Cheat Sheet)

| 常見 AI Slop 寫法 | 立即替換方案 (Tailwind / CSS) | 預期改進效果 |
| --- | --- | --- |
| `bg-gradient-to-r from-violet-600 to-indigo-600 text-white rounded-2xl` | `bg-neutral-900 text-white rounded-sm hover:bg-neutral-800` | 消除廉價漸層，回歸俐落經典工藝感 |
| `text-center max-w-2xl mx-auto` (用於全頁段落) | `text-left max-w-prose` (靠左對齊，限制閱讀長度約 65 字元) | 大幅提升長文易讀性與專業編輯感 |
| `py-16 md:py-20` (約 64–80px) | `py-32 md:py-44` (約 128–176px，桌面端維持 160px+) | 徹底消除擁擠模板感，創造大器留白 |
| `font-bold text-3xl md:text-4xl` (36px, 700 weight) | `font-medium text-4xl md:text-6xl tracking-tight` (56px+, 500 weight) | 靠尺寸拉開層級，告別笨重粗體 |
| `grid grid-cols-1 md:grid-cols-3 gap-8` (等寬三卡片) | `grid grid-cols-1 md:grid-cols-12 gap-8` (左 5 欄標題導引、右 7 欄交錯項目) | 破除僵化模板，建立不對稱視覺張力 |
| `bg-emerald-500/10 text-emerald-500 rounded-full p-2` 包覆 Checkmark | 直接保留純文字列表，或僅以 `1px` 細線分隔項目；去除裝飾圓圈 | 消除「未完成草稿」套路，版面回歸清爽 |
| `focus:outline-none` (粗暴移除焦點樣式) | `focus-visible:ring-2 focus-visible:ring-offset-2 focus-visible:ring-neutral-900` | 符合 WCAG 無障礙標準，鍵盤操作友善 |

## 4. 直接觀看與視覺閉環檢核項 (Direct Visual Checkpoints)

在交付任何前端代碼前，必須逐項核對以下視覺觀看程序：

- [ ] **啟動即時預覽**：已透過本地 dev server 或 `scripts/serve_preview.py` 啟動預覽，非純靜態盲猜代碼。
- [ ] **瀏覽器直接觀看**：已透過瀏覽器或 `browser` subagent 載入頁面，取得全頁真實渲染畫面。
- [ ] **遠看焦點測試 (Squint Test)**：縮小至 25% 觀看，確認全頁有且僅有 1 個核心視覺焦點，無雜亂發光光球。
- [ ] **計算樣式實測 (Computed Styles)**：
  - 桌面端各 Section 之實際 `paddingTop` / `paddingBottom` ≥ `160px`。
  - Display 標題實際 `fontSize` 與內文之比值 ≥ `3.0` 倍。
  - 主標題實際 `fontWeight` 為 `400` 或 `500`。
- [ ] **跨斷點直接觀看 (Responsive Inspection)**：
  - [ ] 桌面端（1440px）：不對稱 12 欄網格呼吸感充裕。
  - [ ] 平板端（768px）：雙欄折疊合理，圖表未被截斷。
  - [ ] 行動端（375px）：主標題折行自然無孤字、無水平滾動軸（X-overflow）。
- [ ] **微調後再次觀看確認**：每次修改樣式後重新載入並直接觀看對比，確認 16 項標誌已降至 0–1 項。
