# 人本設計與認知科學基礎指南 (Methodology & Cognitive Science)

本文件深入梳理人類設計師在動手繪製視覺或撰寫代碼前，所依循的流程架構與人類視覺認知科學原理。它為 AI 提供了不可撼動的「設計決策合理性背書」。

---

## 1. 雙鑽石模型與設計思考五步驟

### 1.1 雙鑽石模型（Double Diamond）
由英國設計委員會（Design Council）提出的雙鑽石模型，是現代設計流程的基礎骨架。它由兩組「發散（Diverge）」與「收斂（Converge）」循環構成：

```
        發散            收斂            發散            收斂
     (探索未知)      (定義核心)      (發想解法)      (驗證定案)
      
       /\              \/              /\              \/
      /  \            /  \            /  \            /  \
     /    \          /    \          /    \          /    \
    /      \        /      \        /      \        /      \
   /        \      /        \      /        \      /        \
  / Discover \    /  Define  \    / Develop  \    /  Deliver \
  \          /    \          /    \          /    \          /
   \        /      \        /      \        /      \        /
    \      /        \      /        \      /        \      /
     \    /          \    /          \    /          \    /
      \  /            \  /            \  /            \  /
       \/              \/              \/              \/
  [發現真實問題]   [鎖定設計焦點]   [探索多元設計]   [交付系統規格]
  
  <------ 鑽石一：做對的事 ------>   <------ 鑽石二：把事做好 ------>
```

- **第一鑽石（探索與定義）**：
  - **Discover（發現）**：從使用者痛點出發，廣泛同理其操作背景、情緒阻力與真實內容。
  - **Define（定義）**：收斂發現，剔除雜訊，鎖定真正值得解決的 1~2 個核心任務，以 HMW (How Might We) 形式形成觀點陳述。
- **第二鑽石（發想與交付）**：
  - **Develop（發展/發想）**：探索多種視覺架構、版面配置、色彩搭配與互動路徑。
  - **Deliver（交付/收斂）**：透過「頭腦互搏（Adversarial Critique）」過濾缺陷方案，對抗審查邊界狀態，收斂為具體的 Design Tokens 與狀態機規格書。

### 1.2 設計思考五階段（Design Thinking）
史丹佛 d.school 與 Nielsen Norman Group (NN/g) 強調的五階段人本循環：
1. **同理（Empathize）**：理解真實使用者的情境與限制（例如手持單手操作、強光戶外、視力退化或認知疲勞）。
2. **定義（Define）**：以使用者為中心重構問題，不以「我們想做一個好看的按鈕」思考，而是「使用者如何在一秒內確認款項已安全送出」。
3. **發想（Ideate）**：打破思維慣性，不套用既定範本，探索包括開放式畫布、儀表排版或敘事流等多元解法。
4. **原型（Prototype）**：以 Token、排版格線與元件解剖結構建立高保真規格原型。
5. **測試與批判（Test & Critique）**：透過嚴苛的易用性檢驗與反模式審查，驗證假設。

## 2. 內容優先原則（Content-First Principle）

在傳統瀑布流或缺乏經驗的 AI 生成中，常見的嚴重缺陷是：先畫出好看的卡片盒子，再往裡面塞 `Lorem ipsum dolor sit amet`。當上線遇到真實世界的資料時，排版瞬間崩潰（例如姓名長達 24 個字元、數字破千萬、多語系長度膨脹 40%）。

人類設計師恪守 **內容優先（Content-First）**：
1. **真實資料推演**：先取得或假設真實世界的代表性資料（極短、典型、極長、空值、特殊字元）。
2. **文案決定寬度**：由文字的閱讀舒適長度（45~75 字元）決定容器寬度，而非由螢幕均分三等分反推文案。
3. **微文案（Microcopy）即導航**：按鈕、提示文字與錯誤訊息不是點綴，而是指示操作路徑的符標；明確寫出動詞與受詞（例如「儲存並繼續結帳」優於模糊的「送出」）。

## 3. 視覺認知與格式塔心理學（Gestalt Principles in UI）

人眼在觀看介面時，大腦會下意識根據**格式塔組織法則（Gestalt Laws of Grouping）**對元素進行分群與解讀。成熟的設計師用空間與色塊引導大腦，平庸的介面則依賴大量不必要的黑線外框。

### 3.1 格式塔五大原則在 UI 之實務對照

| 原則 | 人類視覺機制 | 優秀設計實踐 (Do) | 反模式 (Don't) |
| :--- | :--- | :--- | :--- |
| **接近性 (Proximity)** | 彼此靠得近的元素會被視為同一個關聯單元。這是排版中**最強大**的組織力量。 | 表單 Label 與對應 Input 的距離為 `4px~8px`；而該 Input 與下一個表單欄位的距離必須拉大至 `24px~32px`。 | Label 與 Input 距離 `16px`，但欄位與欄位間距也是 `16px`，導致使用者視覺無法分群。 |
| **相似性 (Similarity)** | 具備相同形狀、色彩、大小或字體的元素，會被視為具有相同功能或重要級別。 | 全站 Primary CTA 維持統一的幾何圓角（如 `8px`）與品牌填色；所有次要操作連結統一使用底線或微暗語意色。 | 在同一個頁面中，有的主按鈕是膠囊形、有的是直角，有的帶陰影、有的帶漸層，混淆使用者對操作權重的認知。 |
| **共同區域 (Common Region)** | 落在同一封閉背景色塊或邊界內的元素，會被感知為獨立實體。 | 使用極淡的底色容器（如 `Surface Container`）將整組關聯統計數據包裹起來，省去每項數據之間的分割線。 | 在每項數據周圍都加上 `border border-gray-300` 甚至深陰影，造成畫面沉重不堪、雜訊過載。 |
| **主體與背景 (Figure/Ground)** | 大腦能自動將畫面分離為突出的前景主體與襯底的安靜背景。 | 彈窗（Modal）出現時，背景加上柔和的遮罩（Scrim）與層疊明度，使使用者專注於焦點動作。 | 彈窗缺乏遮罩，且背景充滿高飽和度的雜亂裝飾，導致前景主體與背景混為一談。 |
| **閉合與連續性 (Closure & Continuity)** | 人眼會沿著視覺暗示的路徑自動補齊隱形輪廓，並偏好平滑連續的線條。 | 水平滑動的輪播卡片（Carousel）在視窗右緣故意露出 `20%` 的卡片邊緣，直覺傳遞「可橫向滑動」。 | 將卡片切齊視窗邊界，使用者誤以為列表已到達終點，錯失後續資訊。 |

## 4. 互動心理學：可供性、符標與心智模型

數位螢幕表面是平滑的玻璃或像素，本質上不存在物理凹凸。因此所有互動完全仰賴人類的認知關聯：

### 4.1 可供性（Affordance） vs. 符標（Signifier）
Don Norman 在《設計的心理學》（The Design of Everyday Things）中明確指出：
- **可供性（Affordance）**：物件與人之間可能發生的互動關係（例如螢幕表面本質上可以被觸控或點擊）。
- **符標（Signifier）**：任何能夠向人**傳達「這裡可以怎麼操作」**的信號（例如底線、高光、下壓陰影、滑鼠游標從指針變成手指、按鈕邊界等）。
- **警示**：扁平化設計（Flat Design）最常見的災難是「移除了所有符標」，將按鈕做成純文字，讓使用者失去點擊信心。必須保留清楚的符標（如容器外框、背景填充、Hover 微反饋）。

### 4.2 美感即用性效應（Aesthetic-Usability Effect）
- 研究證實：使用者在面對視覺和諧、比例精確、排版精緻的介面時，會產生積極的情緒反應。
- 這種正面情緒會提高使用者的容忍度，使他們在面對輕微的流程摩擦時，更傾向於認為是自己操作失誤而非系統缺陷，從而提升整體產品滿意度。
- **但注意**：美感不能取代可用性；缺乏結構美感的「純裝飾」只會淪為視覺干擾。

## 5. 認知負荷定律（Laws of UX）在系統架構中的約束

人類大腦的工作記憶體（Working Memory）容量極其有限。設計思考的核心在於**主動降低非必要認知負荷（Extraneous Cognitive Load）**：

1. **席克定律（Hick's Law）**：
   - 做出決策所需的時間，隨選擇數量的增加而對數級增長。
   - **實踐**：在單一視圖中控制決策選項。避免同時呈現 8 個同等權重的按鈕；將操作精煉為「1 個 Primary、1~2 個 Secondary、其餘收納於 Overflow 菜單」。
2. **費茨定律（Fitts's Law）**：
   - 到達目標的時間取決於「目標的距離」與「目標的大小」。
   - **實踐**：行動裝置底部的操作命中區至少需維持 `48x48px`（桌面端至少 `36x36px`），並確保主要 CTA 位於最易觸達的拇指熱區。
3. **米勒定律（Miller's Law）**：
   - 一般人在短期記憶中平均只能保持 `7 (±2)` 個資訊塊（Chunks）。
   - **實踐**：複雜表單或儀表板必須執行「資訊分塊（Chunking）」；例如信用卡號每 4 碼空格、多步驟流程採用 Step Progress 分步引導。
4. **雅各定律（Jakob's Law）**：
   - 使用者將大部分時間花在其他網站/應用上，因此他們期望你的系統運作方式與他們已知的經驗一致。
   - **實踐**：避免在基礎互動上「重新發明輪子」（例如搜尋框放在右上或頂部中央、購物車放在右上角、取消在左確認在右或遵循作業系統慣例）。
