# 共用文件契約與交付範本

以下依內容角色提供可裁剪範本，不強制特定檔名或全部章節。先沿用專案既有文件；只有使用者要求保存或維護時才寫檔。範本內的說明必須替換為已確認內容或具體未知，不能留下空白佔位。

## 1. 文件分工與導覽

建立或維護前，先對應內容與主要來源：

| 內容 | 主要文件 | 讀者何時需要 | 維護依據 |
| --- | --- | --- | --- |
| 專案用途與開始方式 | 既有 README | 初次接手 | 需求、入口、scripts |
| 架構與資料流 | 既有 overview／架構文件 | 判斷修改位置 | 目前來源與相關設定 |
| 開發要求 | 既有指南／規則文件 | 執行相關任務 | 明確要求、有效規則 |
| 必要常駐規則與任務索引 | AGENTS.md | 進入作用範圍時 | 原有效規則與明確指示 |

詳細內容每項只有一個主要維護位置；入口可保留簡短導讀與連結。必要常駐約束保留精簡表述，不因消除重複而削弱效力。

## 2. 專案摘要範本

按需求保留章節，讀者應能理解系統用途並找到實際入口。

```markdown
# 專案摘要

## 用途與範圍
服務誰、解決什麼問題、本文件涵蓋哪些應用及排除哪些範圍。

## 模組地圖
模組／目錄 | 職責 | 實際入口 | 主要關聯

## 技術與執行環境
技術／服務 | 用途 | 來源位置 | 已確認或待確認

## 主要資料流
描述已查證的代表路徑，列輸入、轉換、儲存、輸出與來源位置。

## 開發與驗證
任務 | 工作目錄 | 指令 | 必要前提 | 驗證狀態

## 開發要求與閱讀入口
以連結導向主要規則及相關開發指南，避免複製詳細內容。

## 限制與待確認事項
事項 | 已知證據 | 未知內容 | 最小查證方式

## 維護依據
相關來源、核對的版本或狀態、何種變更需要更新本摘要。
```

來源檔案存在只能支持來源描述；宣告的指令不等於執行成功。把「已核對 scripts，未執行」與實測結果分開，避免讓讀者依賴不存在的驗證。

## 3. 固定要求範本

只有明確持續要求或有效現行規則進入此表；慣例與建議另列，不與強制要求混合。

| 規則 ID | 適用範圍 | 觸發條件 | 要求 | 完成／驗證方式 | 依據／狀態 |
| --- | --- | --- | --- | --- | --- |
| 使用專案現有 ID；沒有時採本次穩定簡稱 | repo／目錄／模組 | 何時需遵循 | 具體動作與必要例外 | 如何確認 | 現行文件或明確要求來源 |

少量規則可用段落表達同樣資訊；無需為格式生成 ID 系統。記錄對話來源時用必要摘要與任務資訊，不複製私人對話、憑證或無關個資。

相互衝突的要求不要自行選一個刪除。列出雙方來源、作用範圍、衝突點與需要的決策，將不依賴該決策的內容先完成。

## 4. README 與 AGENTS.md 入口

README 的入口回答「專案做什麼、如何開始、哪裡有更多資訊」。保留使用者原有介紹、語氣、徽章、連結與與本次無關內容。

AGENTS.md 的入口回答「哪些要求持續生效、這類任務需讀哪個文件」。可用下列骨架，但不得直接取代未知來源的既有規則：

```markdown
# 專案工作規則

## 必要常駐要求
保留已確認且須持續生效的規則，維持原作用範圍與要求強度。

## 按任務閱讀
任務類型 | 文件入口 | 何時需要展開

## 驗證與交付
保留必要驗證及交付要求；條件式細節指向對應指南。
```

不能只寫「請閱讀全部文件」，也不能把每次都必須遵守的要求藏在無明確觸發條件的連結後。規則移位時檢查舊項目是否仍可被遵循。

## 5. 文件維護結果

一般回覆以短摘要交付；只有使用者要求維護報告時才保存詳細紀錄。

```text
目標／範圍：涵蓋的 repo、模組、文件與排除項
任務：建立／增量更新／規則整理／僅說明

內容項 | 主要文件 | 來源／依據 | 已完成查證 | 缺口

實際變更：新增或更新哪些段落及閱讀入口
要求整理：固定要求、單次條件、建議與未決衝突如何處理
驗證：路徑、連結、指令來源及實際執行結果
未完成：具體未知、受阻原因與下一步
```

覆蓋可用「已核對」「待確認」「未涵蓋」表達，標示是來源核對或實測；不把文件格式檢查當成系統驗收。摘要中已聲稱的每項主要事實都應能追到來源或具體待確認事項。

## 6. 完成檢查

- 新接手的人能找到用途、入口、相關規則與必要驗證，不依賴本次聊天才能理解。
- AI 能依任務選讀相同詳細內容，不需每次通讀全部文件。
- 原有要求未被意外削弱、擴張或改成不同作用範圍；單次條件沒有被永久化。
- 文件之間連結可用，主要內容沒有平行版本，已變更的舊說法已同步。
- 沒有空白佔位、未證實的成功聲明、秘密或未揭露的關鍵缺口。
